# Computer Service Manager

A desktop computer repair/service management application built with **Python + PyQt6** and **SQLite**.

## Overview

Computer Service Manager helps computer repair shops manage customers, devices, repair jobs, parts inventory, suppliers, warranty tracking, and reports from a single desktop application.

The application includes localization, currency settings, themes, database backup/restore, and export features.

## Features

- Customer information management
- Device/service ticket management
- Repair status tracking
- Technician assignment
- Warranty tracking
- Parts inventory management
- Supplier management
- Purchase invoice records
- Reports and data export
- CSV and Excel support
- SQLite database storage
- Backup and restore support
- Multi-language interface
- Multiple UI themes
- Currency localization

## Technology Stack

- Python 3.x
- PyQt6 desktop GUI
- SQLite database
- OpenPyXL Excel support

## Installation

Clone the repository:

```bash
git clone https://github.com/rahfie27/Computer-Service-Manager.git
cd Computer-Service-Manager
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python "Computer Service Manager.py"
```

## Requirements

- Python 3.10+
- Windows/Linux/macOS
- PyQt6
- openpyxl
